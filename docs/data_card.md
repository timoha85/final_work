# Карточка данных

Дополнительное локальное сравнение A–E использует зафиксированное до первого C/D/E evaluation-ответа подмножество из 18 инцидентов (6 на класс), 8 уникальных источников. Список и независимый от качества алгоритм выбора находятся в data/local_evaluation_selection.json; он выбран по скорости отладочного пилота. Полные A/B на всех 60 инцидентах сохранены отдельно. Основной датасет и разметка при переходе к локальной LLM не менялись.

Источник оценки: [AxonData/Display_replay_attacks](https://huggingface.co/datasets/AxonData/Display_replay_attacks), публичная демоверсия, а не заявленные в карточке 5000+ видео полного коммерческого набора. На момент получения: 5 JPG в Real, 5 видео в Screen, 163757220 байт. Карточка публичного набора объявляет CC BY 4.0, полный коммерческий продукт имеет отдельные условия. Используется только публичная часть без регистрации. Версии байтов фиксируются SHA-256, для HF LFS проверяются хеши API. Исходные URL с main не гарантируют неизменность; для повторения требуются совпадающие хеши. Raw images/videos в архив не включены.

Отладочный источник: [официальные примеры PAD](https://github.com/minivision-ai/Silent-Face-Anti-Spoofing/tree/master/images/sample), image_T1/F1/F2. Эти три кадра имеют демонстрационные real/fake метки разработчика. Репозиторий Apache 2.0; отдельные права на изображения не описаны, поэтому они также не распространяются в архиве. Это не валидированный независимый биометрический бенчмарк.

Протокол и manifest разделяют источники целиком. Кадры одного видео не пересекают split. Все три официальных кадра относятся к debug, все Axon — evaluation. Идентичность субъектов и исходные отношения real/replay не документированы поставщиком sample; поэтому для контроля split все Axon считаются одной консервативной группой, все official другой. Межсубъектная независимость по неизвестным людям и отсутствие совпадений между поставщиками не доказаны. Равные хеши проверены автоматически, распознавание личности не выполняется.

`data/source_manifest.json`: source_id, group_id, URL, локальный путь, split, визуальная метка поставщика, статус, license, SHA-256. `frame_manifest.json`: индексы кадров и хеши извлечённых JPEG. `incidents.jsonl`: внутренние инциденты и контекст (ссылки на source_id остаются только локально). `labels.jsonl`: отдельная сценарная разметка и stress/latent поля; агент её не видит. `visual_cache.json`: фактический локальный PAD inference и ошибки. Для LLM передаётся только AgentInput из белого списка.

Генератор `scripts/generate.py`, seed 8217: debug 10, evaluation 60. Оценка сбалансирована по сценарным классам (20/20/20), но использует лишь 10 уникальных источников: 5 фото для bona_fide и injection и 5 видео для presentation. Это повторные контекстные испытания, а не 60 независимых людей. Изображения не модифицируются для имитации реальной инъекции. Внедрение моделируется сценарной доставкой real-фото через подменённый канал, а не deepfake-генерацией.

Реальны: пиксели, тип файла, индексы кадров, выводы PAD и измеренное время. Метки real/spoof предоставлены источником. Синтетичны: incident_id, способ доставки, телеметрия, история, клиентская заметка, контролируемая недоступность инструмента. observed_by у синтетики означает предполагаемую роль наблюдателя в сценарии; это не утверждение о реальном сборе серверных логов. Provenance сохраняет synthetic.

Генератор выбирает вероятностные поля с перекрытием распределений benign и атак. Набор содержит benign со странной телеметрией, малозаметные injection, конфликты, отсутствующие channel/history, принудительный PAD failure и текстовую инструкцию в клиентской заметке. Не все случайные сочетания обеспечивают заметную конфликтность: фактический состав и признаки доступны для проверки. История только предшествующая. UUID и клиентские заметки не зависят от истинного класса, имена файлов/сценариев не передаются LLM.

Этот набор нельзя использовать для выводов о демографической справедливости, реальной частоте атак, надёжности PAD на незнакомых людях, идентификации личности и устойчивости настоящего capture pipeline.
