# Ограничения и границы применимости

1. C/D/E используют небольшую локальную Qwen2.5-1.5B-Instruct Q4_K_M; выводы не переносятся автоматически на более сильные LLM. Статус фактического выполнения и общий размер выборки записаны в report_materials/STATUS.md. Юнит-тесты с test double не являются экспериментом LLM. Платные и удалённые вызовы запрещены.
2. Оценка содержит 60 сценариев на 10 уникальных медиаисточниках. Повторный контекст на одном фото или видео зависим. Не заявляются статистическая значимость, доверительные интервалы по 60 независимым наблюдениям или межсубъектная обобщаемость.
3. Телеметрия и инъекция синтетические. Распределения выбраны исследователем, сценарные метки не доказывают реальный взлом камеры, наличие deepfake или подмену личности. PAD не подтверждает личность.
4. PAD не калиброван под эти камеры и условия. Качество на исходной визуальной задаче и качество рекомендации по сценарию — разные вещи. Real-фото может выглядеть live для PAD и при этом использоваться в сценарной инъекции.
5. Демонстрационный sample не репрезентативен. Условия согласия и происхождение установлены только по публичному описанию поставщика, независимо не аудировались. Исходные лица и видео не включены в передаваемый архив.
6. B — простой фиксированный эвристический baseline; не использует историю в формуле решения. Пороговые правила не оптимизировались по evaluation. D включает консервативный merge, E имеет больше рассуждающих вызовов, поэтому разницу нельзя приписывать одной только многоагентности без учёта токенов/времени.
7. temperature=0 не гарантирует детерминизм API. Точная серверная версия может отличаться от запрошенного model ID; если API сообщает её, она сохраняется. Неизвестный прайс не заменяется предположением о цене.
8. Проверяется отсутствие ground truth в входе агента и запрет неизвестных ссылок evidence_id; не проверяется истинность каждой формулировки обоснования. Ссылки на реальный ID не гарантируют логической достаточности свидетельства.
9. Prompt injection включена в недоверенную заметку. Тесты проверяют структурную изоляцию и поведение правил; эмпирическая защита LLM требует выполненного API-прогона. Один сценарий даже при успехе не доказывает абсолютной защиты.
10. Время PAD включает сохранение кадров, исключает загрузку модели/сети. Время B очень мало и шумно; не является промышленным benchmark. Таймаут сетевого вызова 40 с не равен жёсткому общему дедлайну процесса.
11. manual_review может повышать безопасность ценой нагрузки оператора; поэтому оцениваются coverage, benign reject/escalate и selective accuracy совместно. Сбои не удаляются из знаменателей.
12. Система только выдаёт рекомендации, не интегрирована с промышленной биометрией, не принимает реальных решений о доступе и не прошла security audit.
