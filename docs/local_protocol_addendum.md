# Дополнение до первого локального LLM-ответа

2026-11-02. Пользователь запретил платные вызовы и разрешил проверить небольшую локальную LLM. Исходные A/B на 60 инцидентах сохраняются без изменений. Ранее их результаты уже просмотрены; локальное сравнение является дополнительным экспериментом, с этим фактом следует ознакомить читателя. Исходные prompts, правила и merge не меняются по ответам evaluation.

Выбрана официальная Qwen2.5-1.5B-Instruct, GGUF Q4_K_M, 1117320736 байт; Apache-2.0. Runtime llama.cpp b12032 CPU Windows x64, 24582754 байта, MIT. Фактические revision, хеши и загрузки фиксируются отдельно. RAM всего 31.55 ГиБ, доступно при проверке 13.79 ГиБ, CPU 12 потоков, диск 332.94 ГиБ. Intel UHD Graphics обнаружена через реестр; отдельная CUDA GPU/VRAM не подтверждена. WMI недоступен. Серверы и файлы моделей в стандартных каталогах не обнаружены. Проверка не является полным поиском по всем дискам.

Только loopback HTTP-сервер, никакой передачи внешним API. Ключ и денежный бюджет не нужны. Стоимость API 0 USD, энергопотребление не измеряется. Ограничения прежние: 40 секунд на вызов, 600 выходных токенов на вызов, 4 вызова/2400 токенов на метод, одна перепроверка. Температура 0, seed 8217. Для всех C/D/E применяется один JSON schema constrained decoder; он ограничивает форму, не выбирает сценарный класс и не генерирует обоснования. Семантические ссылки evidence_id по-прежнему проверяются программно. Это изменение транспортного формата относительно исходной внешней API-ветви, одинаковое для всех локальных методов.

Порядок: один реальный структурированный ответ только на debug, затем один debug-инцидент C/D/E. Если первый цикл практически работоспособен, размер основного набора выбирается только по суммарному времени и числу вызовов, не по качеству ответов. При возможности проводится дополнительный небольшой debug-пилот. Лимит времени основной серии — ориентировочно 25 минут, с резервом на оформление. Число инцидентов округляется до кратного трём; плановый верхний размер 30, минимум 6. Оценку времени брать из measured seconds per incident (сумма C/D/E) с запасом 1.5×. Подмножество фиксируется JSON до первого C/D/E evaluation-ответа, stratified по трём истинным классам, seed 94017, без использования результатов A/B или C/D/E. Один и тот же список для A/B/C/D/E, без исключения ошибок. Полные A/B не смешиваются с новым подмножеством.

Более маленькая локальная модель ограничивает перенос выводов на более сильные LLM. Отрицательный результат, abstention и отказы формата допустимы. При практической невозможности ограничиваемся реальными smoke/pilot-артефактами с конкретным объяснением; имитация запрещена.
