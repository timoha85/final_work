## Ограничения

Изменение совместное: финальная схема, stage-инструкции, распределение одной проверки и fail-closed при техническом отказе. Содержательные SYSTEM/ROLES и merge сохранены. Сравнение не изолирует одну компоненту. Маленькая квантованная LLM, 18 зависимых инцидентов / 8 источников, синтетическая телеметрия и доставка. Порядок методов и prefix cache влияют на время. JSON schema не исправляет семантические ошибки классификации. API cost=0; локальное электричество/CPU не монетизируются.
