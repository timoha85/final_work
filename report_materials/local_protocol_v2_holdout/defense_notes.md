# Инструкция для защиты: новые источники при frozen v2

1. **Цель.** Проверить, сохраняются ли ошибки на новых медиа, а не улучшить метрики. V2 не менялась, SHA-256 поведения совпали; один реальный прогон.

2. **Новизна.** 8 новых файлов, 4 Selfies и 4 видео физических атак; 18 сценариев, по 6 на класс. Исключено 10 файлов-копий старого sample, выполнены SHA-256/pHash/provenance и локальный визуальный просмотр. Это не независимость личностей и не неизвестный поставщик.

3. **Результат.** B/C/D/E: macro-F1 0.315/0.311/0.259/0.267; unsafe allow 1/7/5/6 из 12. Benign hard reject 0/2/4/3 из 6. Review B=13/18, C/D/E=0. Высокая coverage LLM не означает корректность.

4. **Injection.** Ни один C/D/E не выдал injection_attack. Два/три/три injection отвергнуты как presentation; это не правильная атрибуция. Precision injection=N/A при отсутствии предсказаний, recall/F1=0 при шести реальных сценарных положительных случаях.

5. **E.** Риск сохранился: 6/12 атак пропущены, PA 3/6 и injection 3/6. Конкретный пример b055a521…: verifier выводит live video из одного фото и придуманного threshold, ссылаясь только на v0 и игнорируя контекст. См. reviewed_errors.md.

6. **B.** Меньше опасных allow/hard reject, но B уходит в review 72.2%; selective accuracy 4/5 надо произносить вместе с coverage 5/18. Это не готовая промышленная защита.

7. **Почему не сравниваем как улучшение старое/новое?** Другие источники, физические инструменты вместо только replay и новый synthetic seed. Таблица old_new_separate_cohorts.csv не парная и не объединённая. Вариацию нельзя причинно отнести только к source generalization.

8. **Не подогнали ли данные?** Выбор файлов/seed/IDs/labels/cache заморожен до первого вызова; PAD failure h01 не исключён. Прогон не повторялся ради красивого результата. Unit-тест воспроизводит generator output побайтно.

9. **Что проверяет тест?** Поведение фиксированной системы на новых для проекта файлах в том же полусинтетическом генераторе. Не реальные capture injection, подтверждение личности, fairness или статистически значимое преимущество.

10. **Можно ли открыть архив без модели?** Да, Markdown/CSV/PNG/SVG и сохранённые traces доступны без модели. Полный compute требует Python/dependencies, публичных media с SHA-256, прежних PAD/LLM weights и llama.cpp; точные команды docs/holdout_reproduce.md. Не называем архив автономным.

11. **Были ли реальные нейросетевые вызовы?** Да: 126 локальных LLM-запросов, реальный PAD по 16 кадрам (один detector failure), 0 платных API, никакого обучения. Test doubles только в unit tests, не в predictions.
